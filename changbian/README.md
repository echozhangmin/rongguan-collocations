# 《續資治通鑑長編》中「冗官」的检索与搭配分析

为研究北宋冗官问题，对李焘《续资治通鉴长编》全书（维基文库四库本）做关键词密度检索、KWIC 检索行和搭配词分析（方法同 DHG502 Assignment 1，qhchina `find_collocates`）。

## 语料

- 来源：中文维基文库《續資治通鑑長編（四庫全書本）》，公有领域。
- 经 MediaWiki API 下载全部 513 卷（原书 520 卷，佚失的 7 卷即传世本所缺，见 `download.py`）。
- 正文共 4,149,461 字；李焘自注 12,955 条、730,404 字，清洗时**单独抽出**（`data/changbian_notes.txt`），本分析只针对正文，注中命中另行标注。
- 四库本**无标点**：正文连排，句子切分不可能。因此以**卷**为分词单位（`max_sentence_length=None`），窗口不跨卷；这是与《通鉴》分析（有标点、以句为单位）的主要方法差异。

## 文本准备（`clean.py`）

- wikitext 模板处理：`{{YL|年号}}` → 保留年号文本；`{{SK notes|…}}`（李焘自注）→ 抽入注文件；`{{SKchar|N}}`/`{{SKchar2|N}}`（四库缺字）→ `□`；`{{SK anchor}}`、页眉页脚模板 → 删除。
- 每卷去掉"欽定四庫全書""宋李燾撰"等四库版式字样。
- 输出：`data/changbian_main.txt`（每卷一行）、`data/manifest.json`（行号 ↔ 卷号）。

## 分析（`analyze.py`）

- 分词：繁转简（OpenCC）→ jieba（**关闭 HMM**，文言文会凭空造词）→ 用户词典（冗官、冗兵、冗食、滥官、滥赏、差遣、磨勘等）。
- 搭配词：`find_collocates`，窗口 ±5、±10，Fisher 精确检验 + BH FDR 校正（显著性），logDice（强度）；共 4 个结果：`冗官` 单目标 × 2 窗口，`冗官+冗员` 合并目标 × 2 窗口。
- 检索指南：`results/keyword_density.csv`（11 个关键词 × 卷计数：冗官 冗員 冗兵 冗費 冗食 濫官 濫賞 省官 任子 僥倖 磨勘）；`results/kwic_rongguan.txt`（冗词族逐条检索行，带卷号、年月、注标记）；`results/compare.html`（4 个运行的前 20 对比页）。

## 主要事实（供精读导航）

- 正文 `冗官` 31 次（16 卷），李焘自注 2 次；`冗员` 19 次、`冗兵` 34 次、`冗费` 40 次、`冗食` 26 次、`滥官` 8 次、`滥赏` 14 次。
- **最密集：卷 143（仁宗庆历三年九月），14 次**——范仲淹《答手诏条陈十事》"抑侥幸"条 + 枢密副使富弼论"御盗四事"与"冗官利害六事"（"去冗官则民之科率十分减九……"），庆历新政前夜的核心文献。
- 其余依次：卷 140（2 次，庆历三年三月改革前奏）、卷 32（1 次，太宗淳化二年，最早的"省冗官"论）、卷 386（2 次，元祐吏禄之费）、卷 262（1 次，熙宁"诏减将作监冗官十六员"，变法实做）、卷 161/166/167（治平减冗）、卷 355/361/376（元祐裁汰）、卷 402/413（徽宗朝）。
- 搭配词：两窗口下 `去`（11–12 次，p < 1e-12）居首，`汰`、`裁`、`省`、`减` 随后——北宋语境中"冗官"首先是一个**等待裁除的对象**；与《资治通鉴》中"乞冗官"（求授闲职）的语义形成鲜明对照。

## 运行

```bash
pip install -r requirements.txt
python download.py    # 维基文库 API 下载 513 卷 wikitext（约 1 分钟）
python clean.py       # 清洗，正文/自注分离
python analyze.py     # 密度表 + KWIC + 4 个搭配运行 + compare.html
```
